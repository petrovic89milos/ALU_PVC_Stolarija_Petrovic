# ALU/PVC Stolarija – Petrovic

📌 **Završni (maturski/diplomski) projekat**

Ovaj projekat je **maturski/diplomski rad** rađen kao završni rad na Visokoj školi i predstavlja **web aplikaciju/web prezentaciju za upravljanje proizvodnjom i narudžbinama ALU i PVC stolarije**.  

---

## 🚀 O projektu

Aplikacija omogućava:

- **Pregled i upravljanje narudžbinama**
- **Unos i praćenje elemenata stolarije**
- **Interaktivno prikazivanje podataka o proizvodima**
- **Responsive korisnički interfejs za desktop i mobilne uređaje**

Projekat demonstrira znanje iz oblasti web razvoja, rada sa bazama podataka i praktičnu primenu alata za verzionisanje koda.

---

## 🛠️ Korišćene tehnologije

Ovaj projekat koristi sledeće tehnologije:

- **HTML / CSS** – struktura i stil korisničkog interfejsa
- **JavaScript** – interaktivnost na klijentskoj strani
- **PHP (ili drugi backend jezik)** – serverska logika
- **MySQL / PostgreSQL (ili druga baza)** – baza podataka
- **Git & GitHub** – verzionisanje i praćenje istorije promjena
